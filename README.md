## 🎮 About the Game

Combolands: Roguelike Citybuilder is an indie strategy game developed and published by Crux Games. It released on August 24, 2026. The game combines city building, deckbuilding, procedural generation, and roguelike progression in short single-player runs.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer enhances Combolands runs by modifying resources, building placement, combo scoring, map interactions, unlocks, and progression. It is designed around the game's core systems: selecting two guilds, placing building cards on procedural islands, creating spatial synergies, collecting heirlooms, recruiting councillors, and advancing through increasingly difficult ranks.

**Target Audience:** Suitable for players who want to experiment with guild combinations, test building synergies, explore procedural islands, accelerate unlocks, or create relaxed city-building runs without changing the game's core strategy focus.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Building Resources** — Prevents selected construction resources from being consumed while placing buildings during a run.
- **Unlimited Potions** — Keeps map-manipulation potions available for repeated use.
- **Freeze Run Values** — Locks selected run counters and economy values so they remain unchanged while you plan and expand your city.
- **Combo Score Multiplier** — Applies a configurable multiplier to combo and score gains generated by building placement and spatial synergies.
- **Unlimited Building Placement** — Allows buildings from the current selection or hand to be placed without normal placement restrictions.
- **Building Upgrade Control** — Supports building upgrades by preserving upgrade-related values and reducing the cost of experimenting with different behaviours.

### 🌍 World

- **Reveal Procedural Map** — Reveals hidden sections of the current procedural island to make available terrain and opportunities easier to evaluate.

### 📌 Progression

- **Unlock Guilds** — Unlocks guild choices so more combinations and distinct city-building playstyles are available between runs.
- **Unlock Heirlooms** — Makes collectible passive heirlooms available for builds that benefit from additional run modifiers.
- **Unlock Councillors** — Unlocks city councillors and their progression options for expanded strategic support.
- **Rank Progression** — Adjusts rank progression to provide access to higher challenge levels without requiring a complete natural progression path.

### ⚔️ Combat

- **No Combat Mode** — Combolands has no conventional combat system. This trainer does not add combat features and focuses exclusively on its city-building, card, map, and progression mechanics.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combolands is played from a strategic overview rather than through direct character movement. Select available building cards, move the cursor across the island grid, and choose valid terrain for placement. Map-related options can reveal terrain and make planning easier, while placement options help test layouts and adjacent-building effects.

### Tools & Inventory

The game's run-based inventory is represented by building selections, heirlooms, upgrades, potions, guild choices, and councillor abilities rather than a traditional character bag. Use resource and potion options before spending them, and avoid changing unlock data while menus or reward screens are open.

### World & Environment

Each run begins on a procedurally generated island. Choose two guilds from the available roster, develop a hamlet into a larger city, and arrange more than 120 possible buildings to create cascading combinations. Map-reveal and placement options are most useful immediately after entering a new island or opening a new area.

### Combat & Weapons

There is no conventional combat, weapon system, enemy roster, or combat encounter loop in Combolands. Progress is driven by construction, spatial effects, economic choices, guild synergies, heirlooms, councillors, and rank challenges. The trainer's combat category is therefore intentionally inactive.
